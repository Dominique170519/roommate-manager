# 合租生活管家 Roommate Manager

年轻人合租时的生活协作工具：**费用 AA 分摊、清洁值日排班、公共物品登记与提醒、室友公约管理**，一个页面管好合租琐事，减少室友矛盾。

## 在线访问

GitHub Pages 部署：https://Dominique170519.github.io/roommate-manager/

> 演示版本：数据保存在浏览器 localStorage（仅本机可见），首次打开自动载入演示数据，可在「设置」中重置或清空。

## 功能

| 模块 | 能力 |
| --- | --- |
| 首页 | 本月支出 / 人均分摊 / 我的净额 / 待采购提醒 / 本周值日 / 公约签署进度总览 |
| 费用 AA | 记一笔费用（描述、金额、垫付人、分类、参与 AA 的人），自动均摊；分类占比环形图、每人垫付柱状图、近 7 天支出趋势、收支净额与最少笔数转账建议 |
| 值日排班 | 厨房 / 卫生间 / 客厅 / 玄关走廊每周自动轮换，打卡完成、历史打卡记录、下周预告 |
| 公共物品 | 物品登记、消耗 / 补货、低库存自动进入采购清单（数量 ≤ 提醒线即预警） |
| 室友公约 | 室友名单管理、公约条款新增与删除、逐人签署状态切换、总体签署进度 |

## 技术说明

- 单文件 HTML（原生 JS + CSS，无构建步骤、无外部依赖），hash 路由切换视图
- 数据模型：`localStorage`（key: `hezu_guanjia_v1`），费用结算使用贪心算法给出最少笔数转账方案
- 演示数据随当前日期动态生成，保证「本月 / 本周 / 近 7 天」等统计始终有内容

## 本地运行

直接双击打开 `index.html`，或在任意静态服务器下访问：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```
